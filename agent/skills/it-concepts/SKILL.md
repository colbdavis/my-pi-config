# IT Concepts

## Teaching style

- Start with a plain-language explanation.
- Then give a precise technical definition.
- Include a tiny terminal example or mental model when possible.
- Compare related terms and call out common misconceptions.
- End with 2-3 quick checks or practice questions if useful.

## Useful structure

1. What it is
2. Why it exists
3. How it works
4. Example command/config/code
5. Troubleshooting or security implications
