# Cysec Study

Use only for benign, defensive, educational, CTF, lab, or explicitly authorized contexts.

## Approach

1. Clarify scope and authorization if the target is a real system.
2. Explain the concept first, then show terminal-friendly examples.
3. Prefer safe local demos: toy services, sample files, localhost, containers, or CTF artifacts.
4. For labs/CTFs, give progressive hints before full solutions unless requested.
5. For defensive work, include detection, mitigation, and hardening notes.

## Boundaries

Do not assist with credential theft, phishing, malware, persistence, stealth/evasion, botnets, unauthorized scanning/exploitation, data exfiltration, or bypassing real access controls. Redirect to safe lab/defensive alternatives.
